## File Structure
- CNAME/README.md - :D
- index.html - Compiled site from Quadpad
- old.md - Legacy backup with more data
- posts.json - Post data. Can use "!GetData <url>"
- occultodeveloper.png - Logo
- qpe_save.qpe - Quadpad editor store, for actually editing the site.

## How to use Quadpad
Quadpad is my personal favorite IDE built into Glacier.
1. Open up [Glacier Dev-only mode](https://glacier.fly.dev?dev-mode)
2. Open "Quadpad" in the taskbar.
3. At the bottom of Quadpad, click the Load QPE button to upload the save data.
4. Modify, and once done, export both QPE and HTML to upload here.
5. :+1:
